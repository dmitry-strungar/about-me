# Дмитрий Струнгарь - Аналитик данных

## Обо мне

Data Analyst с портфолио из 9 проектов в области продуктовой аналитики, ETL и BI-визуализации.    

Специализируюсь на сборе, обработке и анализе данных с использованием SQL и Python, построении ETL-пайплайнов, автоматизации отчётности и создании дашбордов.  

Работал с ключевыми метриками (LTV, CAC, Retention, Конверсия), проводил A/B-тестирование, когортный анализ, исследовал поведение пользователей и формулировал гипотезы для оптимизации продукта.  

Использую AI-инструменты для автоматизации рутинных задач: генерации черновиков кода и запросов, оптимизации DAX, Python и SQL-запросов, формулировки и проверки гипотез, а также подготовки структурированных аналитических выводов.
  
Прошёл программу профессиональной переподготовки по BI-аналитике. В портфолио - проекты от продуктовой аналитики до управленческих дашбордов.  

В репозитории имеется свидетельство о прохождении курса.
